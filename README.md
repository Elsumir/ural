# Тестовое задание: Поиск автозапчастей

Приложение для поиска автозапчастей, брендов, аналогов и предложений складов через API веб-сервиса «Проценка».

## Стек технологий
- React 18
- Redux Toolkit, React-Redux
- Bootstrap 5
- Vite

## Запуск проекта

Установка зависимостей:
```bash
npm install
```

Запуск в режиме разработки:
```bash
npm run dev
```

Сборка продакшн-версии:
```bash
npm run build
```

## Функционал
- Этап 1: поиск доступных брендов по введенному артикулу детали (с задержкой ввода и по нажатию Enter/кнопки поиска).
- Этап 2: получение предложений и аналогов выбранного производителя.
- Вывод итоговой таблицы с наименованием, брендом, артикулом, доступным остатком и ценой.
- Просмотр подробных предложений по конкретным складам для каждой позиции.
- Фильтрация по наличию на складе, типам позиций (основной/аналоги) и строке поиска.
- Обработка состояний загрузки и сетевых ошибок.
